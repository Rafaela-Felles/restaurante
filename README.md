# 🍔 Restaurante Maluco

Prepare-se para administrar seu próprio restaurante!

Neste jogo, você será responsável por atender os clientes, preparar os pedidos e entregar os pratos antes que o tempo acabe. Cada cliente terá um pedido diferente, e você precisará prestar atenção aos ingredientes necessários para preparar cada refeição corretamente.

Seja rápido, organize seus pedidos e tente deixar todos os clientes satisfeitos!

**Objetivo:** Atender o maior número de clientes possível, preparar os pedidos corretamente e conquistar a maior pontuação.
